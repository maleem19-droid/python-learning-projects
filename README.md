# Python Learning Projects

A collection of practical Python projects developed to build programming, problem-solving, and data-handling skills.

## Projects

### 1. User Registration System

A Python-based registration system demonstrating:

- User input validation
- Email and password validation
- Duplicate account checking
- Exception handling
- Lists and dictionaries
- In-memory data storage

### 2. Expense Tracker

A Python-based expense tracking system demonstrating:

- Adding and storing expenses
- Input validation
- Total expense calculation
- Category-wise expense aggregation
- Lists and dictionaries
- Exception handling

### 3. Mini Banking System

A Python-based banking system demonstrating:

- Account creation
- Deposits and withdrawals
- Balance management
- Transaction tracking
- Account summary display
- Exception handling
- Validation of invalid transactions

## Skills Demonstrated

- Python
- Functions
- Lists & Dictionaries
- Loops
- Conditional Logic
- Exception Handling
- Data Validation
- Data Aggregation
- Basic Data Management

## Purpose

These projects were created as part of my hands-on Python learning journey, with a focus on developing practical programming, problem-solving, and data-handling skills.
